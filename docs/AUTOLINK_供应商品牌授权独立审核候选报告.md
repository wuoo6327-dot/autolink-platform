# AUTOLINK 供应商品牌授权独立审核候选报告

日期：2026-10-14。分支基于当前生产通知版本 `ce079be`，与非洲／中东 SEO 候选分开；支付、会员、入驻协议和现有审核结果不变。

## 已实现的边界

- 品牌参考目录、企业身份审核和具体车源审核继续独立。`main_brands` 仅是供应商自行申报，既有供应商不会因旧字段自动获得制造商授权标识。
- 新建与供应商、具体品牌关联的授权申请，记录授权类型、被授权公司法定名称、授权方、业务范围、地区、授权链条、起止日期、私有证明文件、审核人员／时间／结果及操作日志。
- 只有已经获批的企业所有者可以提交申请；申请需绑定仍有效的真实品牌及本企业私有授权材料。授权持有人须与已审核的企业法定名称一致。销售员工、买家不能提交。
- 管理员在原供应商审核页单独查看完整证明和范围，明确确认核查后才能批准；拒绝、撤销需说明原因。只有批准且当前生效、企业仍公开并处于有效状态、品牌仍有效、法定名称未变化、私有证明仍存在时，公开供应商资料才展示受审核的范围和截止日期。
- 授权到期／撤销只撤掉该授权展示；不删除合规独立贸易商身份、企业资料或已审核车源。完整证明及授权链条不进入公开 API 或页面。

## 实际改动

`auth/brand_authorization_service.py` 建立独立的授权记录及核验门槛；`auth/trade_service.py` 扩展私有授权证明类型及公开视图；`auth/app.py` 增加供应商与管理员受控接口；`auth/seo_service.py` 只在真实生效记录存在时输出公开授权范围；`site/supplier/app.js` 在企业资料页增加单品牌提交表单；`site/admin/app.js` 增加私有文件查看与逐项审核；`auth/test_brand_authorization.py` 进行隔离权限、失效与资料泄漏测试。

## 现有数据与验收

生产公开目录当前为 244 个车型、53 个品牌，公开供应商 1 个、公开车源 1 条。生产尚没有品牌授权记录表，也没有经本功能审核通过的授权声明，因此上线后默认公开授权标签仍为 **0**；不得把现有企业／车源审核结果倒灌到新表。

本机专项测试 **3 项通过**；去重后的完整后端测试 **238 项通过、5 项跳过**，原始日志分别为 `/tmp/autolink-brand-auth-tests-final-20261014.log` 和 `/tmp/autolink-brand-auth-full-tests-final-20261014.log`。JavaScript 语法、Python 编译和 `git diff --check` 均通过。Gitleaks 和 Trivy 源码／依赖扫描均完成、发现 0 项（本机 `security-reports/all-sanitized.json`）。原生 Linux AMD64、生产数据备份恢复、私有文件卷安全、容器镜像扫描和回滚演练尚未验收；**本候选未部署生产**。

## 上线门槛与后续操作

先在生产当时最新的一致性备份和私有文件归档上验证独立恢复，在 AMD64 隔离容器运行完整后端、供应商／管理员权限和公开 HTML 测试，并验证现有 1 条公开车源及目录不变。对新表的迁移是 `CREATE TABLE IF NOT EXISTS`，绝不从旧品牌字段批量补授权。固定镜像与文件哈希、检查扫描和回滚，再按现有 Runbook 上线。上线后真实授权的审查仍必须由具备材料和权限的人工审核人员完成；测试 PDF 不能成为生产授权证据。
